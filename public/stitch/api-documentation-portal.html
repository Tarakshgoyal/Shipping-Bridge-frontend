API Reference

Welcome to the Shipping Bridge API. These RESTful endpoints allow you to integrate core logistics functionality directly into your systems. Use the endpoints below to calculate costs and create shipping orders.

POST

Shipping Cost Calculation

/api/v2/shipping/calculate

Calculates the estimated shipping cost based on origin, destination, and package dimensions.

REQUEST BODY (JSON) 
{
  "origin_zip": "90210",
  "destination_zip": "10001",
  "package": {
    "weight_kg": 2.5,
    "length_cm": 30,
    "width_cm": 20,
    "height_cm": 15
  },
  "service_tier": "express"
}
RESPONSE 200 OK 
{
  "currency": "USD",
  "estimated_cost": 24.50,
  "estimated_delivery_days": 2,
  "carrier": "FedEx",
  "quote_id": "qt_8f92j1k2l"
}
POST

Order Creation

/api/v2/shipping/orders

Generates a shipping label and formally creates a shipment order in the system based on a previously generated quote.

REQUEST BODY (JSON) 
{
  "quote_id": "qt_8f92j1k2l",
  "sender_address": {
    "name": "Acme Corp",
    "street1": "123 Tech Blvd"
  },
  "recipient_address": {
    "name": "Jane Doe",
    "street1": "456 Main St"
  }
}
RESPONSE 201 CREATED 
{
  "order_id": "ord_998877",
  "status": "created",
  "tracking_number": "1Z9999999999999999",
  "label_url": "https://api.shipbridge.com/labels/ord_998877.pdf"
}
